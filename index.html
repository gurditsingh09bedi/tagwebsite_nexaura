Editing this site

This is a plain static site — no build step, no backend. Everything you see (tags, colorways, prices, clients) comes from one file: js/data.js.

To add or change a tag, colorway, or price: open js/data.js, edit the relevant array, and re-upload just that one file. Refresh the page — no build, no Actions, nothing else to run.

To add a logo image, drop the file in logos/ and reference it as logo: "logos/yourfile.png" in that tag's entry.
